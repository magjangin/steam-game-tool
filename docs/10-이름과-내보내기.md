# 이름, 분류 및 TXT 내보내기

TXT는 NFC, Unicode 공백 치환/축약, 앞뒤 공백 제거, 곡선 아포스트로피 치환을 적용한
nameKey를 출력한다. 원본 화면 이름과 실제 경로는 보존한다.
번호 1..N, Total, CRLF, UTF-8 BOM 없음 형식을 유지한다.

## 스캔 보존과 범위
list_scanned_games는 선택 범위의 모든 행이다. 앱의 게임만 옵션은 범위를 제한하며,
audit 도구는 게임만 옵션을 끄고 모든 폴더를 출력한다. 범위가 다른 집계를 섞지 않는다.
백엔드 미확정에는 비Unity일 수 있는 항목도 포함되며, Unknown은 비Unity 확정이 아니다.
동일 루트 재스캔에서 이전 경로가 디스크에 남아 있는데 결과에서 빠지면 오류 처리한다.
실제 디스크 추가/제거는 inventory-validation.txt에 기록한다. 분류 변경을 삭제로 세지 않는다.
이 검증은 실행 설정 변경이나 경로가 그대로인 재설치까지 판별하는 검증은 아니다.

## 레이어 증거와 메인 플레이어
각 backendEvidence에 runtime: mono / monobleedingedge / il2cpp / null,
플레이어 경로, 데이터 경로, 런타임 경로, 실행 파일 경로와 크기를 보존한다.
Mono 및 MBE는 Data 내부와 플레이어 루트 두 곳을 검사한다.
Data/Mono 하위의 EmbedRuntime, x86_64 분기는 부모 Mono 경로로 포착된다.
같은 런타임 경로를 별도 플레이어로 중복 기록하지 않는다.

_anniversary는 제외하지 않고 isBundled=true로 남긴다. 번들만 있는 앱도 선택하되 신뢰도 low로 표시한다.
모드/백업 제외 및 __MACOSX/.app 제외는 유지한다.
실제 데이터 후보가 있으면 런타임만 발견한 폴더는 경쟁 후보에서 제외한다.
데이터 후보가 하나면 선택한다. 여럿이면 설치 이름 정확/정규화/접두 일치,
데이터 이름과 대응하는 실행 파일, Managed/metadata 근거, 데이터 폴더 크기,
outer 우선 및 경로순 폴백으로 하나를 선택한다.
selectionConfidence와 선택 사유를 기록한다. 폴더 크기/동률 폴백 및 번들 선택은 low다.
DLC나 번들까지 본체로 단정하는 정책이 아니라, 분류 누락을 막는 검토 가능한 추정이다.
backend는 관측 합집합, classifiedBackend는 선택 플레이어 기준이다. 목록은 후자를 사용한다.

## 분할
Unity 목록 = Mono ∪ IL2CPP. 둘은 서로소다.
전체 스캔 = Mono ∪ IL2CPP ∪ backend_unresolved.
Mono = legacy ∪ MBE ∪ runtime_unresolved. 세 집합은 서로소다.
legacy는 선택 Mono 플레이어에 런타임이 확인됐고 MBE가 아닌 경우다.
런타임 프로브가 전혀 해결되지 않은 Mono는 runtime_unresolved에 남는다.
이는 Mono에서 MBE와 미확정 버킷을 뺀 여집합이며 플레이어별 독립 legacy 술어가 아니다.
생성기는 실제 필터 출력의 집합 교집합/합집합을 검증하고 실패하면 출력을 중단한다.
근거 추가만으로 다른 게임이나 다른 플레이어의 런타임이 분류를 덮어쓰지 않는다.

## 중첩 신호 두 개
list_nested_player_games: 실제 하위 Unity 데이터 증거. 구조 신호다.
list_shadowed_name_games: Unity 관측 항목 중 동일 이름 하위 폴더 존재. 기존 이름 신호다.
list_samename_game_folders: Unity 근거 없는 항목까지 포함한 모든 동일 이름 폴더다.
Jaded는 이름 신호에 남으며 구조 신호에는 들어가지 않는다.
이 신호들은 백엔드 분할과 독립이다. 앱의 보기 목록은 전체 Unity, Mono, 레거시, MBE, IL2CPP, 중첩의 6개만 노출한다. 동일 이름 중첩과 미확정 목록은 audit 검증 출력에 보존한다.

## 생성 파일
ExportLists가 UI와 audit의 이름/헤더/검증을 공유한다.
list_runtime_unresolved.txt와 list_backend_unresolved.txt는 비어도 audit에서 생성한다.
classification-review.txt는 Unity 증거는 있지만 메인 분류가 미확정인 항목의 근거를 보여준다.
이전 list_nested_unity_games.txt는 audit에서 구조 기반 목록과 동일한 내용으로 갱신한다.
검증 JSON은 schemaVersion 4이며 앱 저장 형식은 계속 TXT다.

## 추가 보존 검사와 저장 호환
scanned = unity ∪ non_unity ∪ player_unresolved를 실제 집합으로 검증한다.
non_unity는 Steam 정보가 알려져 있고 Unity 근거가 검출되지 않은 항목이다.
엔진을 확정한 뜻은 아니다. 정보가 없거나 근거가 불충분한 항목은 player_unresolved다.
nested_player는 unity ∪ player_unresolved의 부분집합이어야 한다.
이전 Unity 경로가 설치된 상태로 분류 목록에서 빠지면 오류 처리한다.
앱 재실행 간 기준은 LocalApplicationData/SteamGameTool/scan-baselines에 루트별로 저장한다.
첫 실행 전 과거 기록을 자동 복원하지는 못한다. audit는 기존 scan.json을 기준으로 비교한다.

앱의 기본 중첩 파일명은 기존 list_nested_unity_games.txt다.
앱 저장은 사용자가 선택한 TXT 한 개만 생성한다. 검증 목록과 별칭 일괄 생성은 audit 도구에서만 수행한다. 보기 메뉴는 6개를 유지한다.
「6개 모두 저장…」은 보기 메뉴 6개 항목만 선택한 폴더에 기존 파일명으로 저장한다(ExportLists.WriteAll).
검증은 한 번 수행하고 모든 텍스트를 만든 뒤에 쓰므로 검증 실패 시 파일을 남기지 않는다. 내용은 개별 저장과 같다.
