# 01. 개요

## 한 줄 요약

내 PC에 설치된 Steam 게임을 전부 훑어서, **어떤 게임이 Unity로 만들어졌는지** 그리고 **그 Unity 게임이 Mono와 IL2CPP 중 무엇을 쓰는지** 목록으로 뽑아 주는 Windows 데스크톱 도구입니다.

## 왜 필요한가

Unity 게임은 C# 코드를 최종 실행 파일로 만드는 방식이 두 갈래입니다.

- **Mono** — C# 코드가 `.dll` 형태로 게임 폴더에 **거의 원본 그대로** 들어 있습니다.
- **IL2CPP** — C# 코드가 C++을 거쳐 네이티브 기계어로 **갈려 들어가** 있습니다.

이 차이는 겉으로는 전혀 보이지 않지만, 게임을 다루는 쪽에서는 작업 방식이 통째로 달라집니다.

| 하려는 일 | Mono | IL2CPP |
|---|---|---|
| 모드 로더 설치 | BepInEx (Mono 빌드), MelonLoader | BepInEx IL2CPP 빌드, MelonLoader (IL2CPP 모드) |
| 코드 열어 보기 | dnSpy/ILSpy로 바로 읽힘 | Il2CppDumper 등으로 메타데이터 복원 필요 |
| 난이도 | 낮음 | 높음 |

문제는 **게임 하나하나 폴더를 열어 확인해야 안다**는 점입니다. 라이브러리에 게임이 300개 있으면 300번 폴더를 뒤져야 합니다. 이 도구는 그걸 한 번에 합니다.

## 누가 쓰는가

- **모더 / 모드 사용자** — 어떤 모드 로더를 깔아야 하는지 미리 확인
- **리버서 / 보안 연구자** — 분석 난이도별로 대상 선별
- **게임 개발자** — 다른 팀이 어떤 백엔드를 택했는지 시장 조사
- **그냥 궁금한 사람** — 내 라이브러리에 Unity 게임이 몇 개나 있나

## 무엇을 하는가

1. **스캔할 폴더를 자동으로 찾습니다.** 레지스트리의 Steam 경로, 드라이브마다 흔한 Steam 설치 위치, `libraryfolders.vdf`에 적힌 모든 라이브러리, 드라이브 최상위에 따로 둔 Unity 게임 폴더까지 봅니다. 폴더를 직접 지정할 수도 있습니다.
2. `appmanifest_*.acf`와 `appcache\appinfo.vdf`를 읽어 **무엇이 게임이고 무엇이 사운드트랙·소프트웨어·도구인지** 가려냅니다([09-앱 종류 판별](09-앱-종류-판별.md)).
3. 게임 폴더마다 Unity 흔적(`*_Data`, `Managed`, `MonoBleedingEdge`, `global-metadata.dat` 등)을 찾아 **Mono / IL2CPP**를 판정하고, Mono는 다시 **구형 레거시 / MonoBleedingEdge**로 나눕니다([04-판별 로직](04-판별-로직.md)).
4. 색깔 배지가 달린 목록으로 보여 주고, **보기 6가지**로 거르고, **TXT 파일로 내보냅니다**([10-이름과 내보내기](10-이름과-내보내기.md)).
5. 체크한 게임에 **MelonLoader를 한 번에 설치**합니다([11-MelonLoader 설치](11-MelonLoader-설치.md)).

## 무엇을 하지 않는가

명시적으로 범위 밖인 것들입니다. (일부는 [07-개선 로드맵](07-개선-로드맵.md)의 후보입니다.)

- **스캔은 게임을 수정하지 않습니다.** 게임 폴더의 파일을 쓰거나 지우거나 실행하지 않습니다. 스캔이 쓰는 파일은 `%LOCALAPPDATA%\SteamGameTool\scan-baselines\`의 기준선 파일뿐입니다([10-이름과 내보내기](10-이름과-내보내기.md)「이전 스캔 대비 누락 검사」).
- **모드 로더는 MelonLoader만, 사용자가 누를 때만 설치합니다.** 체크한 게임 폴더에 zip 내용을 추가합니다. 기존 파일은 덮어쓰지 않습니다. 버전이 규칙과 다른 옛 MelonLoader만 바꾸고(교체 기본 켜짐), 교체를 끄면 건너뜁니다. BepInEx와 모드 자체는 설치하지 않습니다 ([11-MelonLoader 설치](11-MelonLoader-설치.md)).
- **스캔은 네트워크를 쓰지 않습니다.** Steam API도, 스토어 조회도 하지 않습니다. 전부 로컬 파일시스템 검사입니다. 게임 이름과 종류도 Steam 이 이미 디스크에 저장해 둔 파일에서 읽습니다. 네트워크는 「MelonLoader 설치 ▸ 자동 설치…」가 GitHub에서 MelonLoader 릴리스를 받을 때만 씁니다.
- **Unity가 아닌 엔진은 구분하지 않습니다.** Unreal, Godot, MonoGame/FNA 게임은 「백엔드 미확정」으로 세어지고 Unity 보기에는 나오지 않습니다.
- **DRM이나 보호 기능을 건드리지 않습니다.**

숫자는 2026-09-22 이 PC의 라이브러리 기준입니다. 요약 줄과 상태 줄의 전체 형식은 [09-앱 종류 판별](09-앱-종류-판별.md)「화면에 나오는 것」에 있습니다.

- 「폴더 ▾」: 찾아보기… · 폴더 추가… · 자동 감지

- 「MelonLoader 설치 ▾」: 자동 설치… · zip 직접 선택… · ☑ 다른 버전이 설치된 게임도 교체

## 기술 스택 한눈에

| 항목 | 내용 |
|---|---|
| 언어 / 런타임 | C# / .NET 10 (`net10.0-windows`) |
| UI 프레임워크 | Avalonia 12.0.5 (Fluent 테마, Inter 폰트) |
| 아키텍처 | MVVM 없음 — code-behind 직결, 컴파일드 바인딩 |
| 외부 의존성 | Avalonia 패키지뿐 (레지스트리·HTTP·zip은 .NET 기본 라이브러리) |
| 소스 규모 | C# 19개 + XAML 2개, 약 2,900줄 (+ xUnit 테스트 171개) |
| 플랫폼 | Windows 전용 (레지스트리 의존) |
