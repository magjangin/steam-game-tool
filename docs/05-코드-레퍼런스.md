## `enum UnityBackend` — `SteamScanner.cs:13`

```csharp

public enum UnityBackend { Unknown = 0, Mono = 1, Il2Cpp = 2 }
```

`[Flags]`입니다. **하나만 고르는 값이 아니라 비트 조합**입니다.

| 값 | 비트 | 의미 |
|---|---|---|
| `Unknown` | `0` | Unity 흔적 없음 |
| `Mono` | `1` | Mono 백엔드 증거 발견 |
| `Il2Cpp` | `2` | IL2CPP 백엔드 증거 발견 |
| `Mono \| Il2Cpp` | `3` | 한 폴더에 둘 다 존재 (런처+본편 등) |

판정은 `|=`로 **누적**됩니다. 한 번 켜진 비트는 꺼지지 않습니다.

### `FindCommonFolders()` — `SteamScanner.cs:173`

```csharp
public static List<string> FindCommonFolders()
```

스캔 대상이 될 `steamapps\common` 폴더를 **전부** 찾습니다.

동작 순서:

1. `FindSteamPath()`로 기본 라이브러리 확보 (`:143`)
2. `<steam>\steamapps\libraryfolders.vdf`를 읽어 정규식 `"path"\s*"([^"]+)"`으로 모든 라이브러리 경로 추출 (`:150`)
3. Steam 기본 설치 위치 `C:\Program Files (x86)\Steam`를 폴백으로 추가 (`:159`)
4. 각 라이브러리의 `steamapps\common`이 **실제로 존재하는 것만** 반환 (`:165`)

중복은 대소문자 무시 비교로 제거합니다.

- **반환:** 존재가 확인된 경로 목록. 하나도 없으면 빈 리스트
- **예외:** 던지지 않습니다. vdf 읽기 실패는 `try/catch`로 잡고(`:154`) 레지스트리로 찾은 라이브러리는 유지합니다

> 3번에 **개인 환경 경로를 추가하지 마세요.** `libraryfolders.vdf`가 이미 모든 라이브러리를 알려주므로 불필요하고, 남의 PC에서는 존재하지 않는 경로를 조회하는 낭비가 됩니다.

> ⚠️ VDF 파싱이 정규식 한 줄입니다. `\\` 이스케이프만 되돌리므로(`:151`) 다른 이스케이프 시퀀스가 든 경로는 잘못 읽힐 수 있습니다. 실사용 경로에서는 거의 문제되지 않습니다.

| 매개변수 | 설명 |

게임 폴더는 `Parallel.ForEach`로 병렬 처리합니다 (`:202`). 폴더마다 하는 일:

2. `InspectUnityInstall(dir)` 호출 → 백엔드 + `Managed` 여부 + 오류를 **한 번의 순회로** 함께 수집

4. 같은 이름 하위 폴더 확인 → `HasNestedMatch`
5. `lock`으로 `ScanResult.Games`·`Warnings`에 추가 (`:230`)

- **반환:** 항상 `ScanResult` 인스턴스. 스캔할 폴더가 없으면 `progress`로 알리고 **빈 결과**를 돌려줍니다 (`:182-186`)
- **취소:** 지원하지 않습니다 ([07-개선 로드맵](07-개선-로드맵.md) 5번)
- **스레드 안전성:** 상태가 없으므로 여러 번 동시 호출해도 안전합니다
- **성능:** 실측 885개 게임 기준 약 0.7초

## `OnMelonAutoClick` / `OnMelonZipClick` / `OnSelectAllClick`

범위 안에서 `SteamGame.InstallChecked`가 켜진 게임만 대상으로 삼습니다(`MelonCandidates(scope)`). 자동 설치의 범위는 `AutoInstallScope()`입니다. 보기와 상관없이 `Filter(_last, Marker.Any, 게임만)`을 씁니다. zip 직접 선택의 범위는 `_view`(지금 보기)입니다. 두 설치 버튼의 흐름은 이렇습니다.

- **자동**: `Inspect` → `MelonReleaseClient.FetchAsync` → `RequiredDownloads` → `GetZipAsync` → `OpenPackage(zip, 버전)` → `PlanAuto`
- **직접**: zip 선택 → `OpenPackages` → `Plan(games, packages, replace)`

둘 다 마지막에 `ConfirmAndInstallAsync`(`TextDialog` 확인 → `InstallAll`)로 끝납니다. 「다른 버전이 설치된 게임도 교체」(`MelonReplaceCheck`, 「MelonLoader 설치」 메뉴의 체크 항목)가 `replace` 값입니다.
목록 위 「MelonLoader 설치 대상」 체크박스(`SelectAllCheck`)는 `_view`에 있는 게임만 바꿉니다. 하나라도 풀려 있으면 모두 체크하고, 모두 체크돼 있으면 모두 풉니다. 체크 상태는 `UpdateSelectAll`이 체크(모두)·해제(없음)·미정(일부)과 `체크 수 / 전체` 개수로 보여 줍니다. 다시 스캔하면, 이전 결과에서 체크가 풀려 있던 `InstallDir`은 새 결과에서도 풀린 상태로 둡니다.
