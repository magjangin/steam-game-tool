## 문서 규칙

- **코드 참조는 `파일:줄번호` 형식**으로 씁니다 (예: `SteamScanner.cs:294`). 코드가 바뀌면 줄 번호도 같이 고쳐 주세요.
- **판별 규칙을 바꾸면** [04-판별-로직.md](04-판별-로직.md)를 반드시 함께 갱신합니다. 이 문서가 도구의 신뢰성을 설명하는 유일한 근거입니다.
- **앱 종류 판별을 바꾸면** [09-앱-종류-판별.md](09-앱-종류-판별.md)를 함께 갱신합니다.
- **공개 API를 바꾸면** [05-코드-레퍼런스.md](05-코드-레퍼런스.md)를 갱신합니다.
- 비유는 [02](02-비유로-이해하기.md)에만 둡니다. 다른 문서는 사실만 씁니다.
