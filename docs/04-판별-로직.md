# 판별 로직

현재 스키마와 분할 정의는 [이름과 내보내기](10-이름과-내보내기.md)를 참조한다.

설치 폴더 아래 최대 8단계에서 *_Data를 찾고 각 플레이어의 근거를 보존한다.
루트 후보가 있어도 하위 후보를 검사한다. il2cpp_data는 플레이어로 세지 않는다.
모드/도구/백업 및 __MACOSX/.app 제외 규칙은 유지하되 _anniversary는 번들 플래그로 보존한다.

각 플레이어는 global-metadata.dat 또는 GameAssembly.dll + UnityPlayer.dll 쌍이 있으면
IL2CPP다. 그 증거가 없고 대표 Unity 어셈블리 또는 Managed+Mono 런타임이 있으면 Mono다.
Mono/MonoBleedingEdge는 플레이어 루트 및 Data 내부를 모두 검사한다.
런타임만 발견된 후보도 경로와 규칙을 기록한다.

관측 backend는 합집합이며 게임 목록 classifiedBackend와 다르다.
게임 분류는 이름·실행 파일·데이터 근거·크기·outer/경로순 폴백으로 후보를 선택하며, 선택 신뢰도를 기록한다. 번들이나 동률을 이유로 게임을 폐기하지 않는다.

생성 시 Mono/IL2CPP/백엔드미확정의 전체 스캔 분할과
legacy/MBE/런타임미확정의 Mono 분할을 검증한다.
이름 일치와 구조 기반 중첩은 별도 신호이며 별도 TXT/필터로 제공한다.
